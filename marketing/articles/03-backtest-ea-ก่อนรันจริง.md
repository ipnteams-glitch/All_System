# วิธี backtest กลยุทธ์ EA ก่อนรันพอร์ตจริง (ต้องดูอะไรบ้าง)

> คำอธิบายสั้น (ใช้เป็น excerpt / meta description เวลาโพสต์):
> ก่อนปล่อย EA เทรดเงินจริง ต้อง backtest ให้เป็น บทความนี้สรุปขั้นตอนและตัวเลขสำคัญที่ต้องดู แบบเข้าใจง่าย

ก่อนเอา EA (บอทเทรด) ไปรันกับเงินจริง สิ่งที่ห้ามข้ามคือ **backtest** — การทดสอบกลยุทธ์กับข้อมูลราคาย้อนหลัง
backtest ที่ดีช่วยให้เห็นว่าระบบเคยทำงานยังไงก่อนเสี่ยงเงินจริง บทความนี้สรุปให้ครบ

## backtest คืออะไร

backtest คือการจำลองการเทรดของ EA บนข้อมูลราคาในอดีต เพื่อดูผลลัพธ์โดยไม่ต้องเสียเงินจริง
ใน MetaTrader ทำผ่าน Strategy Tester ได้เลย

## ขั้นตอนพื้นฐาน

1. เลือกคู่เงิน/สินค้า และกรอบเวลา (เช่น XAUUSD M15)
2. เลือกช่วงข้อมูลย้อนหลังที่ยาวพอ (อย่างน้อยครอบหลายสภาพตลาด)
3. ตั้งคุณภาพข้อมูลให้สูง (tick data ถ้าทำได้)
4. รันแล้วอ่านรายงานผล

## ตัวเลขที่ต้องดู (อย่าดูแค่กำไรรวม)

- **Max Drawdown:** เงินเคยติดลบหนักสุดกี่ % — ยิ่งต่ำยิ่งทนได้
- **Profit Factor:** กำไรรวม ÷ ขาดทุนรวม ควรเกิน 1 พอสมควร
- **จำนวนไม้:** น้อยเกินไป = สถิติเชื่อไม่ได้
- **เส้นทุน (equity curve):** ควรค่อย ๆ ขึ้น ไม่ใช่กระโดดแล้วดิ่ง

## กับดักที่พบบ่อย

- **Overfitting:** ปรับค่าจนสวยเป๊ะกับอดีต แต่ใช้จริงพัง — ทดสอบช่วงข้อมูลที่ไม่เคยปรับด้วย
- **ข้อมูลคุณภาพต่ำ:** spread/slippage ไม่สมจริง ทำให้ผลหลอก
- **ดูแค่กำไร:** ลืมดู drawdown แล้วเจอของจริงทนไม่ไหว
